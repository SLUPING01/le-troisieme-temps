# Le Troisième Temps

Site vitrine du barber shop Le Troisième Temps, réalisé avec Next.js App Router.

## Développement

```bash
npm install
npm run dev
```

Le site est disponible sur <http://localhost:3000>.

## Pages

- `/` : accueil et présentation du salon
- `/coupes` : prestations et tarifs
- `/rendez-vous` : formulaire de demande de rendez-vous

Le formulaire prépare un e-mail dans la messagerie du visiteur ; le rendez-vous
n'est confirmé qu'après une réponse du salon.
